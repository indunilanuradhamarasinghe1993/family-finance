How to record expenses

Enter actual spending as it happens. Each entry belongs to the selected salary cycle (25th–24th), even if a bill was paid using cash or a personal card. You can edit or delete entries later.

Do not enter savings transfers as expenses; use the Savings tracker instead.

For credit cards: recording the payment as an expense is fine for this cash-flow budget, but avoid also recording the same purchases as expenses or you will double-count.

How to read the figures

Planned expense = category budgets. Actual expense = entries recorded in the expense tracker. Actual savings = savings transfers recorded. A month with no transactions is shown as “not recorded”, not as proof that no money was spent. Joint buffer is planned joint funding minus actual spending, and is only a cash-flow estimate because some expenses may be paid outside the joint account.

Data management & privacy

Everything is stored in this browser using local storage. It does not sync across devices or browsers. Clearing browser data can erase it.

Important: Download a backup regularly. If you use another laptop or browser, import your backup there. This file alone does not include your recorded data.

Reset all tracked data

This permanently removes all monthly records in this browser and restores original budget values.
