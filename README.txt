FAMILY FINANCE — iPhone Home Screen App

1. Upload all files in this folder to a HTTPS static website (e.g., Netlify or GitHub Pages). Keep them together.
2. On iPhone, open the website in Safari, tap Share, and choose Add to Home Screen.
3. Launch Family Finance from the Home Screen. After first loading, it works offline.
4. To simply preview without hosting, open index.html on a computer or phone browser. A local HTML file is NOT a proper installable PWA on iOS.

Your data is stored locally on EACH device. It DOES NOT automatically sync between phones. Export JSON backups from More > Settings, and import when moving devices. Do not use private/incognito mode for permanent records.

Expense tracking follows salary cycle 25th-24th. All initial budgets reflect the values previously provided. The app does not access bank accounts.

To avoid duplicate financial figures, record a credit card payment OR the individual card purchases, not both for the same spending.
